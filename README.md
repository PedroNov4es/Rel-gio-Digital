# Relógio Digital

## Descrição

Relógio digital é um projeto simples que desenvolvi com foco em treinar minhas habilidades com javascrit. Ele utiliza o objeto "Date" para utilizar data e hora atual e exibir na tela.

---

## Funcionalidades

* Faz a instânciação do objeto date para manipular data e hora e exibi na tela. Não necessita de interação do usuário

---

## Tecnologias utilizadas

* JavaScript
* HTML5
* CSS3
